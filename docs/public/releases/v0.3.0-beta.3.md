# v0.3.0-beta.3

This beta makes delivered reports easier to read and packages the cloud deployment adapters added since beta.2.

- Gmail reports include responsive HTML with spaced sections, readable dates, short source links, and a separate wrapped plain-text alternative.
- Email subjects, email bodies, and Discord notification copy use ASCII characters. Original structured reports remain unchanged; encoded links preserve their destinations.
- Notification summaries use concise, plural-aware wording. Escaped HTML and isolated mail headers protect source content and message boundaries.
- Railway volume bootstrap starts the applications without root privileges while retaining the separate runner state directory.
- AWS EKS and Google Kubernetes Engine overlays use retained disks and singleton workloads. Experimental Cloudflare Containers support keeps the daemon separate from execution and requires external Postgres.
- Weekly reading recipes now default to the bounded Wakeplane release feed used in live delivery verification; replace it with your own feeds after checking the response-size limit.
- Existing repository-watch/Discord and weekly-digest/Gmail recipes remain paused by default, with provider credentials configured only on the runner.

## Compatibility and upgrades

CLI, REST, MCP, schedule, and typed-target contracts remain unchanged. No storage migrations are added. Each platform archive includes `wakeplane`, `wakeplaned`, and `automation-runner`; the hosted installer installs the CLI and daemon. Preserve database backups and runner state before upgrading. Stop the previous process before replacing it; do not share one state directory between runner replicas.

Native provider delivery still treats a lost response or interrupted send as unconfirmed and does not automatically resend. Inspect provider history before arranging a new delivery. A completed report does not establish delivery or inbox placement.

## Verification boundaries

Formatting, lint, console and deployment tests, Go vet, race tests, real Postgres integration, generated references, container checks, and archive smoke checks gate publication. A private Railway trial has verified native Discord confirmation and Gmail inbox placement; the updated email was inspected in Gmail. Those results do not establish a completed observation period, full fault-recovery acceptance, or stable 1.0 readiness.

AWS, Google Cloud, and Cloudflare adapters have packaging and configuration checks; live deployments on those platforms have not been verified. Wakeplane remains public beta for one operator on trusted infrastructure. RBAC, multi-tenancy, provider account onboarding, spending enforcement, distributed coordination, and a general DAG engine remain outside this release.
